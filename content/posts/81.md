这次去的铁道博物馆，好吧，我以为是好天气，但是，擦，为毛到星期六起雾了啊，还不小啊，好吧，好消息是，星期天的雾气比星期六大。。。

铁道博物馆东郊馆，真够偏僻的，要不是坚定的跟着路牌走，我估计没人能找到这种比鹫峰森林公园那郊区还偏僻的地方。恩，在市区，只能用隐蔽来形容，刁角，武汉话是这么形容的。那个通票上写着，走过三个红绿灯左转，三个红绿灯，特么是铁路的红黄灯啊，还有两道废弃铁路啊，到了外面连个牌子都没有，只有两条废弃铁路，一辆废弃火车，和一个指示牌，红字白底，“展厅”，要不要这么山寨啊！！！<!--more-->
<a href="http://photo.tuhigh.com/pics/1145/1030/309901t-1770666858_d.jpg"><img alt="" src="http://photo.tuhigh.com/pics/1145/1030/309901t-1770666858_d.jpg" class="alignnone" width="531" height="800" /></a>
贴个图，我太惊讶了，真的博物馆没有牌子（就是像XX博物馆那种），这次不评分了。
<a href="http://photo.tuhigh.com/pics/1145/1030/309901t-1646197907_c.jpg"><img alt="" src="http://photo.tuhigh.com/pics/1145/1030/309901t-1646197907_c.jpg" class="alignnone" width="500" height="332" /></a>
展厅基本上都是火车，各种火车头，就像asdf movie里面，最后那句，I like trains!大部分都是小朋友，室内光线不行，所以照片可能有点糊，将就点吧。
<a href="http://photo.tuhigh.com/pics/1145/1030/309901t-671482112_c.jpg"><img alt="" src="http://photo.tuhigh.com/pics/1145/1030/309901t-671482112_c.jpg" class="alignnone" width="500" height="332" /></a>
最有趣的是朱毛火车，恩，毛爷爷的那个车灯很特别，囧囧有神。
<a href="http://photo.tuhigh.com/pics/1145/1030/309901t-1442386351_d.jpg"><img alt="" src="http://photo.tuhigh.com/pics/1145/1030/309901t-1442386351_d.jpg" class="alignnone" width="500" height="331" /></a>
还有整个绿皮车整进去了一辆，好特么长啊。
<a href="http://photo.tuhigh.com/pics/1145/1030/309901t-1512056624_c.jpg"><img alt="" src="http://photo.tuhigh.com/pics/1145/1030/309901t-1512056624_c.jpg" class="alignnone" width="500" height="332" /></a>
很多地方有隐藏关卡，比如有的火车头和车厢可以进去，老式的蒸汽车那些仪表盘很帅的样子，蒸汽朋克的风格啊，不过太黑照不下来，原谅我吧。然后发现一个问题，火车头的门都很窄，呃，开火车的一定都很瘦，一定的，不然我不会侧着身子才能进去。。。

有个标着试验车的，进去一看车厢，呃，被震慑到了，擦，不比我租的房子差啊，包厢里有床有桌子，还木地板啊！万恶的铁道部
<a href="http://photo.tuhigh.com/pics/1145/1030/309901t-1437189014_c.jpg"><img alt="" src="http://photo.tuhigh.com/pics/1145/1030/309901t-1437189014_c.jpg" class="alignnone" width="500" height="332" /></a>
恩，其他的就是各种各样的囧囧有神的火车头了，参数我并不关心，呃，毕竟展出的都是老式的，基本上都是七十年代前被淘汰的，和谐号神马的，连解说都木有。不过看了参数，其实当时技术还是很牛ca的，车速和拉货重量都还不赖的样子。当然，里面国产货不多，除了一辆绿皮，还有几辆特别的，都是八国联军的，哎，叹口气
<a href="http://photo.tuhigh.com/pics/1145/1030/309901t1235379128_c.jpg"><img alt="" src="http://photo.tuhigh.com/pics/1145/1030/309901t1235379128_c.jpg" class="alignnone" width="500" height="332" /></a>
好了，这个博物馆很坑爹，人也不多，好多小鬼在里面捉迷藏。而且，四点就关门赶人了，所以呢，必须早点去，记住，周边啥都没有哦，没有吃没有喝，除了车位和厕所，当然还有纪念品。

出来照了个小虫子和牵牛花，还是老头的色彩给力。。。
