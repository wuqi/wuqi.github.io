因为新的civiltop笔记本装不成各种带界面的linux(自用推荐linuxmint，稳定不折腾，而且比ubuntu好用)，只能装个arch...

安装过程archwiki上都有(Beginners' guide,非Installation guide)，所以简略记录下，以下为备忘模式：

 - 首先，下载archlinux的iso，因为是滚动安装，需要下最新的iso文件 然后，将用 lili USB Creator 或者 YUMI 创建 liveUSB，一来速度快，二来方便，lili USB Creator
 - 创建的可以隐藏文件（windows下不显示，linux下可以看到），继续当usb使用
 - 在就是启动，联网（我用wifi，所以直接用wifi-menu） 
 - 装vim pacman -S vim（或者也可以用nano、vi）
 - 换源，大家懂得 vim /etc/pacman.d/mirrorlist
 - 分区 cfdis和mkfs.ext4分区，将分区挂载到/mnt（懒，就分一个区）
 - 安装： pacstrap -i /mnt base base-devel
 - 生成 fstab，并检查下是否生成： genfstab -U -p /mnt >> /mnt/etc/fstab
 - arch-chroot /mnt /bin/bash
 - 设置 Hostname locale 时区等等
 - passwd，以及useradd -m -G wheel -s /bin/bash yourname
 - 装grub：pacman -S grub
 - grub-install --target=i386-pc --recheck /dev/sda
 - grub-mkconfig -o /boot/grub/grub.cfg
 - exit
 - reboot

装完了！后面试了下kde5，感觉啥软件都不全的样子，不过很漂亮...中看不中用的草包
